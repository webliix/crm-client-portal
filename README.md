# Webliix Client Portal (login.webliix.com)

Dedicated customer-facing web application for Webliix clients to track project progress, milestone timelines, task checklists, invoice & billing statements, support tickets, and submit project updates directly to developers.

## Features
- **Client Authentication**: Token persistence and authentication integrated with Webliix Backend API.
- **Projects & Milestones**: Live completion progress bar, milestones breakdown, task status, and instruction message board.
- **Invoices & Billing**: Financial summary KPI cards, paid total, pending balance, and invoice status table.
- **Support Desk**: Submit and track technical support tickets.
- **Profile & Settings**: Account details management and secure password updates.

## Tech Stack
- React 19 + TypeScript
- Material UI (MUI) v7
- Vite 8
- Axios HTTP client with JWT interceptors
- React Router v7

## Getting Started
```bash
npm install
npm run dev
```
Dev server runs locally at `http://localhost:5173`.
